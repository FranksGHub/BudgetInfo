Android sucht beim Start die Datei:
android/app/src/main/kotlin/com/example/budget_info/MainActivity.kt

Falls noch vorhanden muss der Name übereinstimmen, kann aber auch fehlen
android/app/src/main/AndroidManifest.xml
package="com.example.budget_info"

Ordnerstruktur im Android‑Projekt - prüfe, ob der Pfad wirklich existiert:
android/app/src/main/kotlin/com/example/budget_info/MainActivity.kt

Package‑Deklaration in MainActivity.kt:
package com.example.budget_info
Wenn dort etwas anderes steht → Crash.

android/app/build.gradle
defaultConfig { applicationId "com.example.budget_info" }
Auch das muss exakt übereinstimmen.

Bei mir fehlte der komplette Pfad unter: "android/app/src/main/kotlin/com/example"

So reparierst du das Android‑Projekt:
Benenne deinen aktuellen Android‑Ordner um in "android_old"
Erzeuge einen neuen Ordner mit:
flutter create .

Projekt neu bauen:
flutter clean
flutter pub get
flutter run
