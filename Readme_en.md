## **The Budget Info App**  
  
### **Overview & First Steps**  
The Budget Info project offers a simple and user-friendly way to manage the remaining (monthly) budget.  
It can also be used as a very simple to-do list, shopping list, etc.  

- **Short Description:**  
It's a list with main and sub-entries. The sub-entries have a status: yellow for "in progress" and green for "completed." When the status changes to green, the current date is recorded. Money transfers can be saved for each sub-entry.  
The purpose of this app was to use an existing budget for each year (main entry) and each month (sub-entry) to deduct expenses and then use the remaining balance at the end of the month as savings (investing the remaining budget and set the status to green).  
  
- **Multilingualism:**
German and English  
  
- **Supported Platforms:**  
Android and Windows  
  
- **Required Permissions:**  
The app only saves its settings to its own document directory and does not require any other permissions. If the user selects Export or Import from the main menu, files must be saved, shared, and read outside the app to save and synchronize the settings.  
  
- **Quick Start Guide for Windows:**  
Copy the ZIP file to a new directory of your choice (e.g., C:\Tools\BudgetInfo) and extract it, for example, using File Explorer. Right-click on the file "budget_info.exe" and select "Pin to Start" so you can easily access it from the Start menu. For updates, simply extract the new ZIP file back into this directory and overwrite the old files.  
  
- **Quick Start Guide for Android:**  
As long as the app is not yet visible in the Google Play Store, save the APK file to your Android tablet or phone and install it using a file manager that has permission (e.g., Google's "Files" app or your browser).  
  
## **App Features**  
  
- **Home Page / Manage Main/Sub Items**  
Essentially the list is a monthly plan for a year. The lists can, of course, also be used for other purposes. Because the text in the list and the filename used to store and reload entries in the lists can be freely chosen, there are no limits to what can be entered in these lists. For example, there could be a task list. Of course, by repeatedly changing the filename of the suggestion list, any items from multiple lists can be added to the list on the left side, and so on.  
Double-clicking on a main entry allows you to change the text.  
Double-clicking a sub-entry opens the details window for that entry. This is described further below.  
  
  
> **The Main Menu:**  
> The app version is displayed here  
> A help window can be displayed  
> The left list can be hidden/shown  
> The right list (templates) can be hidden/shown  
> The list can be printed or saved as a PDF  
> Export settings and data as a ZIP file for backup and data exchange  
> Import settings and data from a previously exported ZIP file  
> The App settings can be changed  
  
  
### **Details**  
  
- **Export/Import**  
The export/import function allows you to create a complete backup of your data and settings at any time. This should be done regularly after making changes. The resulting ZIP file, containing the date, can be saved by the user and imported again at any time. This allows you to manage years, try out different things and so on. Furthermore, data can be easily exchanged between the Windows and Android apps. The app data is identical, but may change from version to version. The same version should always be used on all devices. The version can be found at the top of the home screen menu.  
To delete all files (restore to factory settings), you can do so via the Android built-in "App Info" and "Clear Storage," or using Windows File Explorer in the "Documents" folder under "BudgetInfo". Of course, close the app beforehand.  
  
- **Additional buttons in the home page view**  
The "+ Mainline" button adds a main-entry (main line) to the list, which can then be moved using the up/down arrow buttons. With a doubleclick on a line the text is editable.   
If a Mainline is selected, another sub-entry (sub line) can be added below the selected Mainline using the "+ Subline" button and moved using the corresponding up/down arrow buttons. With a doubleclick on a line the details view is showing up.  
If the right-hand list (template list) is visible, the two buttons "<= Mainline" and "<= Subline" allow you to copy entire Main- and Sublines or individual Sublines from the right-hand list to the left-hand list. To do this, a Mainline or Subline must be selected on the right, and in the case of a Subline, a Mainline must also be selected on the left to insert the Subline.  
The red minus sign in a circle deletes an entire block or a line from a list.  
All changes are saved automatically.  
   
- **Using Status Management in the List**  
The list features a colored status indicator, at the beginning of the Subline, to represent the current status of the item. Currently, the colored circles are yellow for in work, and green for finished. Clicking the colored circle changes the status in the sequence yellow, green and back to yellow. This makes it easy to see which lines have already been completed and which are still pending. Once all Sublines for a Mainline are complete, the block is displayed collapsed when the window is opened, improving clarity.  
    
- **The App Settings page**  
The App title can be changed here.  
The Start budget for new Sublines can be preset here. This can be changed in the details view of each Subline.  
The filename for the list, without the extension, can be changed here (default is "budgetInfoList").  
The filename for the template list, without the extension, can be changed here (default is "templateList").  
Since there is currently no file explorer, note the names, or do an data export and look inside the zip file to find out which files are present.  
All changes are saved automatically.  
  
- **The datails page**  
The "+ Booking item" button adds a entry to the list, which can then be edited using the pencil button or with a doubleclick on the line.  
There is a free text field and an amount field available. This is primarily for recording expenses or income. For example, Lunch - 20.45. Commas or periods are allowed as separators, but not thousands separators. A minus sign before the amount indicates income and is added to the starting budget. Everything else is subtracted from that.  
The red minus sign in a circle deletes this line from the list.  
All changes are saved automatically.  
    
> **The Details View Menu:**  
> The text of the Subline can be changed  
> The start budget of this Subline can be changed  
> The finished time can be changed  
> The details list can be printed or saved as a PDF
